## Open-Source Maintainer Toolkit

I maintain small, practical tools for developers and open-source maintainers. The current focus is agent infrastructure, MCP diagnostics, repository readiness, and privacy-aware workflow automation.

| Project | Purpose |
| --- | --- |
| [mcp-server-doctor](https://github.com/mySebbe/mcp-server-doctor) | Validate JSON MCP capability reports from files or stdin |
| [mcp-permission-policy-tester](https://github.com/mySebbe/mcp-permission-policy-tester) | Scan MCP tool descriptions and schemas for risky permission policy signals |
| [prompt-tool-log-redactor](https://github.com/mySebbe/prompt-tool-log-redactor) | Redact common secrets and PII from plain text and JSONL logs |
| [oss-repo-launch-doctor](https://github.com/mySebbe/oss-repo-launch-doctor) | Check open-source repository launch readiness |
| [context-budgeter](https://github.com/mySebbe/context-budgeter) | Rank repository files against a task query and token budget |
| [coding-agent-eval-harness](https://github.com/mySebbe/coding-agent-eval-harness) | Run deterministic fixture-based evaluations for coding-agent tasks |
| [maintainer-inbox-triage-cli](https://github.com/mySebbe/maintainer-inbox-triage-cli) | Dry-run local triage for GitHub issue and pull-request JSON payloads |
| [agent-trace-lite](https://github.com/mySebbe/agent-trace-lite) | Record simple agent spans/events to JSONL and summarize them |
